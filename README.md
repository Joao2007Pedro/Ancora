# Monitoria Âncora

## Como rodar localmente
1. Clone o repositório
2. Copie `.env.example` para `.env` e preencha com suas chaves do Firebase
3. Copie `firebase-config.js.example` para `firebase-config.js` e preencha
4. Abra `frontend/index.html` no navegador ou use Live Server no VS Code
